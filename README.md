# AudioX

A polished download landing page for AudioX, an upcoming Gorilla Tag audio panel menu.

## Structure
- `index.html` — page structure
- `css/style.css` — visual system and responsive layout
- `js/main.js` — typing title, download feedback, scroll reveal, card motion
- `animations/effects.js` — interactive starfield/parallax effects
- `data/site-data.json` — editable release metadata
- `downloads/README.md` — placeholder for the real release package

## Release file
The current download button intentionally creates a preview placeholder because no real AudioX build has been added yet. Replace the placeholder behavior in `js/main.js` with the final release asset when it is ready.

This project is a community-made Gorilla Tag companion project and is not affiliated with or endorsed by Another Axiom.
